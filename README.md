# For My Pondatii 💗

A complete, responsive, interactive apology mini-site with falling flowers, gift reveals, a Remo-inspired movie moment, five redeemable sweet coupons, and a big final love message.

## Start
1. Unzip the folder.
2. Open the `pondatii-apology` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use VS Code's **Live Server** extension and click **Go Live**.
4. Send the recipient the hosted website URL, or share the folder/ZIP. An `index.html` file alone isn't enough; keep all three files together.

## Customize
- Change the apology message in `index.html` under `data-scene="1"`.
- Change the coupon names and messages in `index.html` under `data-scene="4"`.
- Change the big ending text under `data-scene="5"`.
- Flowers, gift opening, page transitions, and music are controlled by `script.js`.
- Colors and layout are in `styles.css`.

## Notes
- No dependencies, no build, no accounts, no server needed to view locally.
- The optional Google Fonts require internet; fallback fonts are included.
- The built-in music is generated locally with the Web Audio API after a user click.
- Coupon status only lasts until the page is refreshed.
- The Remo line is a brief cultural reference, not a clip or movie soundtrack.
